# Python for Computer Vision with OpenCV and Deep Learning

Course project covering computer vision with OpenCV and deep learning.

Official course: [Python for Computer Vision with OpenCV and Deep Learning](https://www.udemy.com/course/python-for-computer-vision-with-opencv-and-deep-learning/).

The repository contains course materials and project exercises. Its existing virtual environment uses Python 3.12.5.

Install the project requirements with:

```bash
python -m pip install -r requirements.txt
```
